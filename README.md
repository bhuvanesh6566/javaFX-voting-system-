# JavaFX Voting System 🗳️

A desktop voting application built with JavaFX, featuring voter interaction, administration, vote persistence, and result visualization.

## Features
- Voter interface with candidate selection
- Admin authentication
- Candidate management
- Vote counting and result charts
- CSV-based persistence/export
- Auto-save and result refresh

## Requirements
- Java Development Kit (JDK)
- JavaFX SDK/runtime configured for your environment

## Run
Open the project in a Java IDE with JavaFX configured, then run the application's main class.

## Disclaimer
This project is an educational software implementation and is not intended for use in public elections.
