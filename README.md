# Project Documentation

# JavaFX Voting System 🗳️

A desktop voting application built with JavaFX.

## Features
- Voter interface and candidate selection
- Admin authentication
- Candidate management
- Vote counting and result charts
- CSV persistence/export
- Auto-save and result refresh

## Requirements
JDK and JavaFX configured for your environment.

## Run
Open the project in a Java IDE with JavaFX configured and run the main class.

> Educational project; not intended for public elections.
